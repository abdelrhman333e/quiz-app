تشغيل المسابقة
==============
1) ثبّت Node.js (نسخة 16 أو أحدث) من nodejs.org
2) افتح الطرفية داخل هذا المجلد واكتب:   node server.js
3) هيظهر لك عنوانين، افتحهم:
   - الشاشة (كمبيوتر/تلفزيون):  http://عنوان-الجهاز:3000/screen
   - التابلت:                    http://عنوان-الجهاز:3000/tablet
   (التابلت والكمبيوتر لازم على نفس الواي فاي)
4) على تابلت أندرويد: افتح رابط التابلت في Chrome ← القائمة ⋮ ← "تثبيت التطبيق" / "إضافة إلى الشاشة الرئيسية"
   هيشتغل كتطبيق بملء الشاشة.

مكان البيانات
=============
data/questions.json  ← كل الأسئلة (ممكن تعدله بإيدك وتدوس 🔄 تحديث الأسئلة)
data/game.json       ← حالة اللعبة والنقاط
أي سؤال تضيفه من التابلت بيتحفظ في الملف فورًا ويفضل بعد إعادة التشغيل.

ملاحظة: لو الاتصال مش شغال، اسمح لـ Node في جدار الحماية (Firewall) على الشبكة الخاصة.
