المسابقة v2 — حسابات + قاعدة بيانات
1) Supabase: Project ← زرار Connect ← Session pooler ← انسخ الـ URI وبدّل [YOUR-PASSWORD] بكلمة سر القاعدة.
2) Render: New ← Web Service ← اختار المستودع.
   Build Command: npm install     Start Command: node server.js     Instance: Free
   Environment: DATABASE_URL = الرابط اللي نسخته      SESSION_SECRET = أي نص عشوائي طويل
3) افتح رابط Render ← حساب جديد ← بيدخلك التابلت ← "نسخ رابط الشاشة".
تجربة محلية: DATABASE_URL=... node server.js
من التابلت استخدم "تصدير الأسئلة" لتنزيل نسخة JSON، أو "استيراد أسئلة" لإضافة أسئلة نسخة سابقة دون حذف أسئلتك الحالية. تتضمن النسخة ملفات الصوت المرفوعة (بإجمالي أقصى 50 ميجابايت).
التثبيت كتطبيق PWA: افتح رابط الموقع المنشور عبر HTTPS. على Android افتح قائمة المتصفح واختر "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية". على iPhone/iPad افتح الرابط في Safari، اضغط "مشاركة" ثم "إضافة إلى الشاشة الرئيسية". يعمل التطبيق المثبت كواجهة ويب؛ يلزم الاتصال بالموقع لاستخدام الحسابات والأسئلة، ولا ينشئ هذا الإعداد ملف APK أو تطبيق iOS أصليًا.
لإخفاء شريط عنوان Chrome داخل APK المصدّر من PWABuilder (TWA): انشر الملف public/.well-known/assetlinks.json على نفس نطاق التطبيق عبر HTTPS، وتأكد أن الرابط https://نطاق-موقعك/.well-known/assetlinks.json يعرض JSON دون إعادة توجيه إلى صفحة HTML. الملف مرتبط بمعرّف الحزمة وشهادة توقيع APK المرفقين بحزمة PWABuilder؛ إذا أعدت إنشاء التطبيق بمفتاح توقيع أو معرّف مختلف، حدّث الملف بالقيم الجديدة. بعد النشر، أغلق التطبيق وافتحه مجددًا؛ قد تحتاج إزالة APK القديم وتثبيت النسخة الجديدة.
عند التصدير اختر JSON أو TXT أو Excel XLSX أو Word DOCX. JSON يحفظ كل أنواع الأسئلة وملفات الصوت؛ أما TXT/XLSX/DOCX فهي للتبادل وتشمل الأسئلة العادية فقط، وتستخدم قالب الاستيراد نفسه.
يمكن استيراد الأسئلة العادية من TXT بترميز UTF-8 أو Word DOCX بأسطر معنونة لكل سؤال، أو Excel XLSX بأعمدة في الصف الأول:
التصنيف | السؤال | الصعوبة | الاختيار أ | الاختيار ب | الاختيار ج | الاختيار د | الإجابة
مثال TXT/DOCX، افصل الأسئلة بسطر فارغ:
التصنيف: ثقافة عامة
السؤال: ما عاصمة مصر؟
الصعوبة: سهل
الاختيار أ: القاهرة
الاختيار ب: الإسكندرية
الاختيار ج: الجيزة
الاختيار د: الأقصر
الإجابة: أ
الصعوبة والاختيارات اختيارية؛ إذا لم تستخدم الاختيارات اكتب الإجابة كنص. الإجابة مع الاختيارات تكون الحرف أ/ب/ج/د أو نص الاختيار. التصنيف الافتراضي "عام" والصعوبة الافتراضية "سهل". الحد الأقصى 500 سؤال وحجم الملف 10 ميجابايت؛ صيغ Word المدعومة DOCX فقط.

تنظيم ملفات المشروع:
- server.js هو مدخل الخادم، وأدوات الأسئلة وبيانات الأسئلة الافتراضية في server/questions/.
- public/index.html وpublic/tablet.html وpublic/screen.html هي صفحات الواجهة.
- ملفات CSS في public/css/ وملفات JavaScript الخاصة بالواجهة في public/js/.
- أصول الموقع التي تُحمّل عبر المتصفح في public/assets/icons/ وpublic/assets/audio/.
- ملفات التصميم الأصلية غير المقدمة مباشرة للمتصفح في assets/brand/.
- أبقِ public/manifest.json وpublic/sw.js وpublic/.well-known/assetlinks.json في أماكنها؛ لها مسارات ويب ثابتة.
- شغّل الاختبارات باستخدام npm test.
